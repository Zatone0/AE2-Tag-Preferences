# Project artwork

The selected icon combines Applied Energistics 2 15.4.10 terminal textures with Just Enough Items 15.58.0.209's tag badge. Source pixels are retained under source/. The textures were tinted, layered, combined with the badge, and enlarged using nearest-neighbor scaling; the CurseForge version adds a dark background.
